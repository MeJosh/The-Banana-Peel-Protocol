# Character icons

Original PNGs from the [Blood on the Clocktower Wiki](https://wiki.bloodontheclocktower.com/Main_Page), downloaded with `python3 scripts/cache_icons.py`.

`manifest.json` records each character's wiki page, original image URL, dimensions, and SHA-256 checksum. Existing valid files are reused; `--refresh` updates them. Keep icons and the manifest with the project so PDF builds work offline.

Character art belongs to its respective creators and The Pandemonium Institute. The manifest's character-page links provide the wiki's individual artist credits. These assets are not newly licensed by this project.
